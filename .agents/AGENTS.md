# AuditNode Frontend Rules

Use the portable skills exposed through `skills.json`; their canonical source is `../../agent-standards/skills/`.

- Read `design.md` before changing visual components.
- Reuse `src/shared/ui/` components when they meet the required behavior and accessibility.
- Run `npx tsc --noEmit`, `npx vitest run`, and `npm run build` before reporting frontend work complete.
