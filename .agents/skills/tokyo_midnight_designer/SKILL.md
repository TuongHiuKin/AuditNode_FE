# Tokyo Midnight Design System Rules

1. **Bảng màu tĩnh:** Nền dùng `#0B0E1A` / `#141828`. Primary text `#F2F2F5`.
2. **Single Action Color:** Chỉ dùng màu Tertiary (`#FF4D7E`) cho ĐÚNG MỘT thao tác quan trọng nhất trên mỗi màn hình.
3. **CẤM:** Nghiêm cấm dùng Gradient (như `bg-gradient-to-...`). Hệ thống này phải thiết kế phẳng (Flat) hoàn toàn.
4. Tuân thủ Typography: Space Grotesk (Heading/Display), Inter (Body), JetBrains Mono (Label).
